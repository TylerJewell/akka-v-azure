# Scenario library

Nine multi-meeting account simulations. Each runs across three to five interactions with
different people, and the learner routes at every one.

## How a scenario runs

Groups of three: a learner, a facilitator playing every cast member, and an observer holding the scoring sheet. Rotate roles between scenarios so each person runs one and observes two.

The learner sees the account brief and the cast list. The facilitator sees everything,
including the branch outcomes and the hidden information each cast member conceals. Do not
give the learner the branch table.

At each decision point the learner states the solution they are leading with and the second
cost they will name. The facilitator reads the matching branch outcome aloud and the scenario
continues from there. A branch that stalls the deal still runs to the end, because recovering
from a bad route is the harder skill.

Budget 45 minutes to run and 20 minutes to debrief. Debrief against the scoring sheet, then
read the entry-solution line at the top of the file and ask the learner where they diverged.

Run 1, 3, 9, and 10 first, because those four carry the routing failures that cost the most deals.

## Scoring

Every scenario scores the same five things, out of two points each.

| Criterion | 0 | 1 | 2 |
|---|---|---|---|
| Routed on the stated pain | Led with the wrong solution | Right solution, arrived at late | Right solution from the first exchange |
| Quantified the cost in the customer's numbers | No number | Akka's number | The customer's own number |
| Conceded accurately before contrasting | Attacked a competitor | Generic concession | Named what the incumbent is genuinely good at |
| Named a second cost owned by someone absent | None named | Named a cost, no person | Named the cost and the person |
| Secured a dated next step | None | Vague follow-up | A date, a name, and a deliverable |

Eight of ten passes. Two scenarios passed certifies the module.
