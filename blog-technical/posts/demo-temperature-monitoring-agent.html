Demo: Temperature monitoring agent

Andrzej Ludwikowski · Principal Engineer

In this video, Akka engineer Andrejz showcases a temperature-monitoring solution designed to gather, consolidate, and analyze IoT sensor data. Leveraging the Akka SDK and AI, the system uncovers temperature trends and detects anomalies across various sites. Data is collected and aggregated using Key Value Entities, with OpenAI models driving the trend and anomaly detection.
