Demo: MCP support in Akka

Johan Andrén · Principal Engineer
Jul 9, 2025 · 1 min read

In this video, Johan, our Principal Engineer on the Akka team, dives into the Model Context Protocol (MCP). MCP is the industry-standard API framework that enables LLM-based agents to interact with external tools and data sources in a consistent, structured way. Johan will also demonstrate how the Akka SDK elevates MCP-powered workflows into robust, scalable, and resilient applications.
