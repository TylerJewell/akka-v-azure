About this webinar

The Akka Edge documentation contains full sample projects in Java and Scala and a step-by-step guide going through the APIs and the implementation of those projects.

This short webinar (12 mins) walks you through the sample system domain and architecture. It covers the new Akka Edge features used in the sample to build a system that spans from the cloud to the edge of the cloud.
