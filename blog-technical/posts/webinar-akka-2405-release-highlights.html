Webinar: Akka 24.05 release highlights

Team Akka
May 29, 2024 · 1 min read

About this webinar

Tyler Jewell, CEO; Jonas Boner, founder and CTO; and Michael Nash, CISO, delve into the value and power of the new features and enhancements in Akka 24.05.

What they cover:

  • Security & compliance - Features and architectural support that now include Zero Trust
  • Performance - Database sharding without specialized partitioning support
  • Efficiency - Java 21 compatibility / Akka Edge Rust / GraalVM native image / active-active / and more
