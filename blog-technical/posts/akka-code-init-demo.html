About this video

Build, test, and run agentic systems in moments using the Akka CLI code init feature.

See how to use code init to quickly develop agentic systems from templates. This 1 minute video shows how easy it is to get started with a new Akka project using the code init feature in the Akka CLI.

You'll walk through creating an application by simply selecting from a range of built-in templates—like agentic workflows, event-sourced systems, and multi-agent setups. You'll see how the CLI integrates with your preferred AI coding assistant (e.g. Cursor, Windsurf, Qodu...) by automatically adding Akka documentation as context.

In just a few clicks, you're up and running with a fully functional Akka project.
