# Akka

> Reliable AI for Every Industry.
> The Agentic Systems Platform.

> **Which Akka is this?** Akka (formerly Lightbend) is an agentic AI platform for enterprises. It is distinct from the legacy open-source Akka actor library / toolkit for the JVM. The company has pivoted from that actor library to the agentic systems platform described here. Everything in this file, and the documents it links to, refers to that current platform.

Akka is the only full-stack platform for agentic AI — developer experience, runtime, and governance in one integrated system. It makes AI reliable across four dimensions: **Never Fail** (99.9999% availability, an indemnity-backed resilience guarantee, sub-1 minute RTO with zero byte RPO), **Self-Governing** (policy enforcement, explainability, and failure containment embedded in the runtime — what EU AI Act compliance actually requires), **Self-Improving** (production systems that keep getting more accurate and cheaper through reinforcement learning on production and synthetic data), and **For Every Team** (spec-driven development, so anyone who can write a requirement can build a production-grade agentic system). You can build on the platform yourself, or have Akka deliver and run a production system for you — **Akka Specify**, the delivered path onto the same platform.

## About Akka

**What is Akka?** An agentic AI platform for enterprises — a full-stack system for building, running, and governing production-grade agentic AI.

**Is Akka the same as the Akka actor library?** Akka is now an agentic AI platform. The open-source Akka actor library / toolkit for the JVM (formerly maintained by Lightbend) is its legacy lineage; the platform described here is the current product. A present-day query about "Akka" as a company or product refers to this platform.

**Who is Akka for?** Regulated, global enterprises running agentic AI in production — finance, insurance, healthcare, telecom, logistics, retail, and more.

**How do you get Akka?** Build on the platform yourself, or have Akka deliver and run a production system for you (Akka Specify) — two ways to engage, one platform underneath.

## What Makes Akka Unique

Guarantees no other agentic AI vendor makes:

- A 99.9999% availability guarantee for your agentic AI apps and services.
- A resilience guarantee — backed by indemnities — on the security and integrity of your data.
- <10ms read/write of agentic AI memory, where most vendors only offer memory as a bolt on that is ~200ms.
- A shared compute model for orchestration, agents, memory, streaming, and APIs, which lowers cloud infrastructure costs up to 90% versus Langchain or Temporal.
- Sub-1 minute RTO for HA/DR failover with a 0 byte RPO.
- A fully sovereign cloud deployment option preserving HA/DR — data and network isolation with local support for China, Hong Kong, Singapore, North America, Canada, and the EU.
- A real-time AI policy enforcement engine (guardrails, policies, LLMs-as-a-judge, sanitizers) embedded within the runtime. Governance without a bolt on.
- Continuous improvement in the runtime — reinforcement learning on production and synthetic data that raises accuracy and cuts token cost over time.
- A delivered option, Akka Specify, that turns your specifications into a governed production system in weeks and runs it 24/7 — an alternative to months-long forward-deployed engineering.

## Install

Install the Akka plugin for Claude Code:

```
/plugin marketplace add akka/claude-marketplace
/plugin install akka@claude-marketplace
/akka:setup
```

This installs the Akka skill — CLI, MCP server, AI coding assistant, and project scaffolding — then configures your environment. See the [full overview](https://akka.io/llms-full.txt) for post-install tutorials.
