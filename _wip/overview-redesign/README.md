Iterative redesign of the akka.io/platform/overview deck. Three new slides
(market thesis, Akka Agentic AI Platform, four efficiencies) are being built
up as standalone previews here, then combined with the surviving slides from
`akka-overview/index.html` into a single assembled deck for review.

**Status: WIP.** Nothing here is published. The live deck at
`/akka-overview/index.html` is unchanged.

## How to iterate

1. Edit one of the three preview files (`thesis-preview.html`,
   `platform-preview.html`, `four-efficiencies-preview.html`).
2. Run `python assemble_overview.py` — it copies a fresh
   `akka-overview/index.html` as the base, injects the three preview sections,
   removes the replaced sections, and writes `overview-new.html`.
3. Open `overview-new.html` in a browser to review.
4. Individual previews also work standalone — open any `*-preview.html`
   directly. Add `?audit=1` to `thesis-preview.html` or
   `four-efficiencies-preview.html` for the design-audit overlay.

## Assembly script — how it patches the base

The base file has global CSS rules that would clobber the new slides if left
untouched. The script:

- **Strips overlapping globals** from each preview's CSS (`*`, `:root`, `body`,
  `.inner`, etc.) so preview and base don't fight over baseline styles.
  The `body{...}` strip uses a lookbehind so it does **not** also strip
  `.eff-body{...}` — that bug lost the body-copy colour on the four-efficiencies
  slide in an earlier build.
- **Renames** the platform preview's section id from `#s-platform` to
  `#s-akka-platform` to avoid collision with the existing integrated-diagram
  section, which already owns `#s-platform`.
- **Injects overrides** that (a) force the new `#s-akka-platform` `.pf-msg`
  and `.seg` visible (the base file's `#s-morph` animation hides them by
  default via shared class names), (b) drop the border+background from the
  new cake, (c) size up the right-side body copy on that slide.
- **Reorders** so the existing "integrated platform" slide sits immediately
  after the new agentic-platform slide.
- **Retargets** the "integrations" arrow on the integrated-platform slide to
  point at the *Semantic memory* chip specifically (was hitting the centre of
  the whole "Your systems" container).
